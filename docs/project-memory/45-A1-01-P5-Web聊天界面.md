## 做了什么

- 后端联调：登录响应补 `userId/username/tenantId/roles/permissions`；`/me` 支持 GET+POST 并返回权限码；SSE 写入 `X-Accel-Buffering: no`；会话/消息枚举改 `getCode()`/`fromCode()`；创建会话 `agentId` 可空默认 `default`。
- 同仓新建 `agent-platform-web/`：React 18 + Vite + Ant Design 5 + Zustand。登录、会话列表、fetch SSE 流式聊天、知识检索模式（需 `kb:read`）、历史消息、375 抽屉布局。
- Token 仅存 sessionStorage；SSE 不用 EventSource。
- `npm test`（parseSse 5 条）与 `npm run build`、`mvn compile` 通过。
- 同步 `docs/开发进度.md`、前端进度、未实现清单 A1-01、本目录会话记录。

## 关键决策

- 前端放本仓 `agent-platform-web/`，README 说明可复制到兄弟目录 `D:\mhqf_project\heavenly-craft-agent\agent-platform-web`。
- 接口对齐现网 **POST + JSON**，不按早期 GET REST 文档发明第二套 API。
- 断线只给「重连」按钮，不自动重放用户消息。
- A1-02/03/04 不做，避免把 26 批管理后台一次铺开。

## 踩坑记录

- 浏览器原生 EventSource 无法带 Bearer，必须 fetch 流解析 `event:` 行（Spring SseEmitter 是 named event，不是 JSON 里的 event 字段；解析器两者都兼容）。
- `ConversationCreateRequest.agentId` 原 `@NotBlank`，聊天页没有 Agent 选择器，需默认值。
- 云环境无 MySQL/Redis/LLM，未能端到端打通登录后的真实流式出字。
