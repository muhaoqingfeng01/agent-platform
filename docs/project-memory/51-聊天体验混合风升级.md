## 做了什么

### 后端
- 新增 `StreamRegistry` / `StreamSessionService`：streamId 注册、取消、重生编排
- SSE 首事件 `stream_started`；`POST .../messages/cancel`、`POST .../messages/regenerate`
- 对话/RAG 管线尊重取消标志；重生跳过用户消息重复落库，旧助手消息保留
- `MessageRepository` 增加 `findByMessageId` / `findPreviousUserMessage`
- 单测：`StreamRegistryTest`、`StreamSessionServiceRegenerateTest`

### 前端（`agent-platform-web`）
- 混合风主题（默认深色可切浅色）+ CSS tokens + Ant Design theme
- 组件拆分：ChatShell / Sidebar / Header / MessageList / EventBlocks / Composer
- Markdown + 代码高亮；停止生成；重生；知识库下拉；会话重命名/删除
- SSE 解析扩展；`npm test` / `npm run build` 通过

## 关键决策
- 布局：侧栏 + 居中对话列；工具事件仅 UI 占位
- 重生策略：保留旧助手消息并追加新消息
- 本轮不做管理后台与真实工具调用

## 踩坑记录
- PowerShell 下 Maven `-Dtest=A,B` 与 `-Dsurefire.*` 需整体加引号
- `SseEmitter.complete()` 在单测中不一定同步触发 onCompletion，cancel 需显式 unregister
- 取消后须保留 `cancelledIds`，否则管线 `isCancelled` 会因注销而失效
