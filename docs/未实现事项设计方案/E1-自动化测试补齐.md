# E1 自动化测试补齐实现方案

> **类别**: E | **优先级**: P1  
> **现状**: 仅 `AgentPlatformApplicationTests`

## 1. 场景

接线（B 类）回归：围栏、mergeConfig、级联删除、缓存 evict 无单测极易回退。

## 2. 设计要点

不追求一次全覆盖。按风险分层：

| 层 | 工具 | 范围 |
|----|------|------|
| Domain | JUnit | 状态迁移、枚举 fromCode、DagParser 无环 |
| Application | Mockito | Pipeline 中间件、mergeConfig、resolveChunkConfig |
| Infra | Testcontainers 可选 | Redis 缓存、SQL 拦截器 |

禁止每个测试起全 Spring（慢）。Boot 测试仅给 Filter 链/登录。

## 3. 实现步骤

1. 各模块 `src/test` 目录约定。  
2. 第一批用例清单：B1 阻断、B10 覆盖顺序、B11 mock milvus 被调、B12 cache、C4 JSON、B7 非法迁移。  
3. CI：`mvn test`。  
4. 覆盖率门槛先 0，接线 PR 必须带测。

## 4. 验收

`mvn test` 在无 Docker 下 Domain+Application 纯测通过。

## 5. 风险

Testcontainers 在云 CI 需 Docker，可标记 `@EnabledIf`。
