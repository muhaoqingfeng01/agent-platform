# D3 结构化日志与聚合实现方案

> **类别**: D | **优先级**: P3  
> **现有**: logback 按天文件，非 JSON

## 1. 现状

文本日志难检索 tenantId/traceId。

## 2. 场景

按 traceId 秒级搜一次失败对话。

## 3. 设计要点

prod profile 使用 `logstash-logback-encoder` JSON：timestamp、level、traceId、tenantId、userId、logger、message。dev 保持可读文本。

采集：Filebeat/Promtail → Loki 或 ELK。一期推荐 Loki（与 Grafana 一体）。

## 4. 实现步骤

1. `logback-spring.xml` springProfile prod 加 JSON appender。  
2. 禁止日志打印 Prompt 全文（可截断）。  
3. `deploy/loki/` 示例。  
4. Grafana Explore 示例查询 `{app="agent-platform"} |= "traceId"`。

## 5. 验收

一条 JSON 含 MDC 四元组。

## 6. 风险

JSON 体积；滚动策略保持 300MB。
