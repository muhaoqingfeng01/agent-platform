# 数据库脚本说明

## 唯一维护入口

**[`agent_platform_full.sql`](agent_platform_full.sql)** — 全量脚本（建库 / 升级追加都用它）

| 场景 | 做法 |
|------|------|
| 新环境初始化 | 建库 `agent_platform_dev` 后整文件执行 |
| 后续表结构/种子变更 | **追加到文件末尾「变更追加区」**，写明时间与作用，并更新文件头变更记录表 |
| 历史分文件 `V1.x.x__*.sql` | 仅作归档对照，**新变更不要只改这些文件** |

### 追加模板

```sql
-- ############################################################################
-- [追加段] 时间: 2026-11-08 15:00  |  版本: V1.9.0  |  作用: 说明本次改了什么
-- ############################################################################
ALTER TABLE ...;
```

同时在 `agent_platform_full.sql` 头部「变更记录」表增加一行。
