| 目录 | 用途 |

---

## 完成任务时的操作（强制）

1. 在 `待办事项/` 找到对应方案（如 `P2-15-B7-对话状态机驱动.md`）。  
2. **移动**到 `已办事项/`（建议去掉 `P*-**` 前缀，与已办命名一致，如 `B7-对话状态机驱动.md`）。  
3. 更新两边的 `README.md` 索引表。  
4. 同步 [`../03-实现进度/进度总览.md`](../03-实现进度/进度总览.md) 状态列为 ✅。  

不要复制留双份；不要只改状态不挪文件。
